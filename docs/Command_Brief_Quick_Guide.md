# Command Brief — Quick Guide (1 oldal)

**Template v1.1 · Részletek: `docs/COMMAND_BRIEF_SOP.md`**

**Heti menet (szerda):** `Weekly → Command Brief → Edit (analyst)` → írd be a neved → oldalanként (Page 1–5) nézd át → szerkeszd a szöveget → **Save** → **Submit for approval** → jóváhagyó: **Approve** → **Release** → Command Brief oldal: **Download PDF** (kanonikus, 5 oldal) · **Download Word** (munkapéldány).

**Szerkesztheted:** a publikációs szöveget (title, what changed, assessment, why Hungary, next observable, alternative, captions, watch / gap / outlook szövegek); átrendezés ↑↓; *Hide*; *revert to generated*.
**Nem szerkesztheted (zárt):** források (S-xx), lineage, publikációs dátum, HU relevance, SIG, CONF, horizon, collection status, forrásjegyzék. Hibás értékelés → elemzői workflow, nem a brief.

| Mező | Szabály |
|---|---|
| Primary KJ | max. **3**; Page 1: HIGH/MEDIUM HU; közvetlen forrás kell |
| What changed | 1–2 mondat, tény |
| Assessment | max. 2 mondat |
| Why Hungary should care | 1–2 mondat, konkrét HU / MH / NATO KKE kapcsolat |
| Next observable | **1** konkrét, ellenőrizhető indikátor |
| Sources | **minden** judgementnél; hivatalos elöl; kontextus ≠ bizonyíték; p.5 = 1 sor / független lánc |
| Collection gap | hiány ≠ inaktivitás |
| Confidence | ≠ significance |
| Published | a cikk dátuma, **soha** nem az eseményé |
| Szöveg | egész mondatok, nincs „…” |

**Státusz:** GENERATED → EDITING → READY_FOR_APPROVAL → APPROVED → RELEASED. Kanonikus PDF csak **APPROVED / RELEASED**; minden más nyomat „WORKING COPY — NOT APPROVED”. Jóváhagyás utáni szerkesztés → vissza EDITING.

**Figyelmeztetések:** *Page N does not fit* → rövidíts · *generated text changed* → restatement volt, nézd át · *reload* → valaki közben mentett.

**Ha a web nem elérhető:** `templates/Command_Air_Intelligence_Brief.dotx` → kattints a szürke helyőrzőkre és töltsd ki (ne töröld a vezérlőket) → térkép: jobb klikk › *Kép módosítása* → források: eredeti nyelvű cím, hiperhivatkozás, publikációs dátum → metaadat-tábla (hét, verziók, státusz, jóváhagyó) → *Mentés .docx* → *Export PDF* (A4 fekvő) → jóváhagyás után terjesztés → a rendszer visszaállása után vidd át a webes szerkesztőbe.

**Nyomtatás:** A4 fekvő, duplex (rövid él), szürkeárnyalatban is olvasható (minden szín mellett szöveges címke).
